# Human-Scanable Organization — Companion Bridge

## Purpose

This file is the companion bridge for non-skill-aware agent runtimes. The
operational SSOT resides in [`SKILL.md`](SKILL.md).

## When This Skill Applies

- You are organizing or reorganizing a collection of items (skills, files,
  docs, menu entries) for human consumption.
- You need to decide when a folder has too many items and needs sub-grouping.
- You want to apply the 8±2 cognitive principle to any information architecture
  task.

## Operational Procedure

Read [`SKILL.md`](SKILL.md) for the full operational procedure, including the
8±2 principle, grouping methodology, and worked example. Do NOT execute any
step without first loading `SKILL.md` — this bridge is intentionally
non-actionable.
