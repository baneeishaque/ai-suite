# KV Line Parse — Companion Bridge

## Purpose

This file is the companion bridge for non-skill-aware agent runtimes. The operational SSOT lives in [`SKILL.md`](SKILL.md).

## When This Skill Applies

When you have a key-value line file (quoted or unquoted key-value pairs per line) and need to parse it to JSON for further processing.

Read [`SKILL.md`](SKILL.md) for the full operational procedure. Do NOT execute any step without first loading `SKILL.md` — this bridge is intentionally non-actionable.
