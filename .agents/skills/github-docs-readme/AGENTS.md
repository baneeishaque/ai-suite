# github-docs-readme

## Purpose
Generate a `docs/README.md` with standard documentation structure.

## When This Skill Applies
A repository has a `docs/` directory and needs a top-level README for it.

## Operational Procedure
1. Run `python3 scripts/write-docs-readme.py --project-name <name> --output docs/README.md`
2. Verify `docs/README.md` was created
