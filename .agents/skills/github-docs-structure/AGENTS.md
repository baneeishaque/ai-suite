# github-docs-structure

## Purpose
Create the standard `docs/` directory tree for a GitHub repository.

## When This Skill Applies
A new repository or project needs a documentation directory structure.

## Operational Procedure
1. Run `python3 scripts/create-docs-structure.py --repo-root <path>`
2. Verify directories were created under `docs/`
