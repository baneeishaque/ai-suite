# github-folder-structure

## Purpose
Create the standard repository skeleton directories for a GitHub project.

## When This Skill Applies
Setting up a new repository that needs standard directory scaffolding.

## Operational Procedure
1. Run `python3 scripts/create-folder-structure.py --repo-root <path>`
2. Verify directories were created
