# AGENTS.md — mise-non-standard-backend-bin-resolve

Companion bridge. The SSOT is [SKILL.md](SKILL.md).

## One-Liner

Print on stdout the absolute path to a binary that `mise` installed via a
non-default backend (`github:`, `ubi:`, `asdf:`, `http:`, …) — for cases
where `mise which <tool>` and `mise where <tool>@latest` both fail.
