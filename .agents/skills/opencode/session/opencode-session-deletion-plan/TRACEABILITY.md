# opencode-session-deletion-plan — Traceability

## Origin

Created 2026-11-04 from a gap-closure pass over an OpenCode
session-deletion workflow. The executed deletion plan carried ad-hoc
content-survival markers that no skill owned, and the deletion composer
consumed them without a plan-authoring contract. This skill supplies the
missing authoring half so the marker baseline, commit roster, gap-closure
gate, and retirement step are produced deterministically.

## Replaces

None. The executor remains
[`opencode-session-deletion`](../opencode-session-deletion/SKILL.md); this
skill is its upstream planning counterpart.

Local-only gap register and skill-documentation plan for the 2026-11-04
session-deletion execution and gap-closure pass. Session identifiers and
