# AGENTS.md — vscode-multi-scope-setting-write

Companion bridge. The SSOT is [SKILL.md](SKILL.md).

## One-Liner

Idempotently write a VS Code setting into multiple scope files (folder
`.vscode/settings.json` and/or workspace `.code-workspace`) so a setting
behaves identically in folder-mode and workspace-mode.
