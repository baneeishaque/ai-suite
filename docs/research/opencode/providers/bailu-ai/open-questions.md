# Open Questions

## Exact Input-Data Limit

No numeric input character/body/message bound was observed in the controlled client tests.
Close this question only with an actual provider error or authoritative model/endpoint-specific published bound,
plus a reproduced original/blank-context comparison. Do not reinterpret declared token windows as character limits.

## Optional Media Input

Provider metadata advertises image/audio/video understanding for several chat models. This audit verifies text/tools,
not every optional transport. Close per model/modality only with a documented request and a real client attachment
outcome. The admitted profiles conservatively expose text input until that additional evidence exists.

## Moving Catalog and Upstream Availability

Some advertised IDs returned unavailable/upstream-busy/edge errors. A successful catalog query is not availability
proof. Re-admission requires a current full direct/client verification under the same no-payment policy.

## Aggregate Token-Counter Attribution

The matched key's aggregate token delta exceeds usage reported by captured direct responses and OpenCode finish events.
Close this question only with a provider request-log/accounting export that maps every counted request/token to the
audit window, or another independently verified explanation. Do not claim the recorded weighted units equal the
aggregate account delta, and do not run more inference merely to investigate accounting.

These limitations do not turn failed/unverified cases into visible models. Current exclusions remain explicit
in the [model policy](evidence/model-policy.csv).
