# VS Code Editor-Tab Compare Extensions Research

## Purpose

Maintain the detailed comparison of VS Code extensions that add "Select for Compare" and
"Compare with Selected" actions to the editor-tab context menu, including the three candidates
the user evaluated (`in4margaret.compareit`, `moshfeu.diff-merge`, `DavidKol.fastcompare`) and
the additional extension that directly implements the requested workflow
(`outofsync42.select-compare-tabs`).
