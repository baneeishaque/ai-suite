# Check Graphify Backends

`check-graphify-backends.py` smoke-tests every entry in the Graphify provider
registry using a freshly generated repository and one Graphify semantic
extraction run per entry.

The checker is intended for the registry generated by
[`generate-graphify-providers.py`](generate-graphify-providers.py.md). It does
not call provider APIs directly. It delegates the request to Graphify's
OpenAI-compatible backend and uses Graphify's exit code and output to classify
the result.

## Usage

Run a live check with the default paths:

```bash
python3 scripts/check-graphify-backends.py
```

The default inputs and outputs are:

| Option | Default | Purpose |
| --- | --- | --- |
| `--providers` | `~/.graphify/providers.json` | Graphify provider registry |
| `--auth` | `$XDG_DATA_HOME/opencode/auth.json` | Authentication fallback values |
| `--repo-dir` | `scratch/graphify-backend-check-repo` | Generated fixture repository |
| `--report` | `scratch/graphify-backend-check-report.json` | JSON status report |
| `--timeout` | `20.0` seconds | Per-request timeout |

The default auth path follows OpenCode's XDG data location and falls back to
`~/.local/share/opencode/auth.json`. Use `--auth` when running with a different
configuration repository:

```bash
python3 scripts/check-graphify-backends.py \
  --providers /path/to/providers.json \
  --auth /path/to/auth.json \
  --repo-dir scratch/backend-check \
  --report scratch/backend-report.json
```

Use `--dry-run` to resolve credentials and report which entries are ready
without making network requests. For entries with credentials, it prints a
single-line command containing the actual key and stores that command in the
corresponding report result:

```bash
python3 scripts/check-graphify-backends.py --dry-run
```

API keys are required for command construction. Entries without a key are
reported as `SKIPPED` and do not receive an executable command. Literal keys
are printed to the terminal and stored in the report JSON, so protect the
report and clear it after use.

## Graphify Contract

Each eligible entry recreates the fixture directory and runs the equivalent of:

```bash
graphify extract <fresh-repo> \
  --backend openai \
  --max-concurrency 1 \
  --timing
```

The entry-specific settings are passed through the child process environment:

```text
OPENAI_BASE_URL=<entry.base_url>
OPENAI_MODEL=<entry.default_model>
OPENAI_API_KEY=<resolved-key>
```

The checker classifies a run as `PASS` only when Graphify exits successfully
and emits its extraction completion line. Graphify errors, model errors, and
timeouts are recorded as `FAIL` with the captured Graphify output.
The exact command is printed for each live entry in copy-pasteable form. The
printed command references `OPENAI_API_KEY` and never exposes the resolved key.
Graphify stdout and stderr are streamed live with entry/stream prefixes and
both complete streams are retained in that entry's report result.

## Credential Resolution

For each registry entry, credentials are resolved in this order:

1. The longest matching provider alias from `auth.json`.
2. The registry entry's `env_key` environment variable.
3. `SKIPPED` when neither source supplies a key.

The report records only the source label, such as `auth:provider` or
`env:PROVIDER_API_KEY`, never the key itself.

## Statuses

- `PASS`: Graphify exited successfully and emitted its extraction completion line.
- `FAIL`: Graphify returned a non-zero exit code, timed out, or omitted its
  extraction completion line.
- `SKIPPED`: No credential was available.
- `READY`: Dry-run mode found a credential without making a request.
- `ERROR`: The registry entry is malformed or lacks required Graphify fields.

The process exits successfully after writing the report, including when
individual backends fail. The printed summary provides counts by status.

## Generated Fixture

The fixture directory is deleted and recreated before every live backend run.
It contains:

- `calculator.py`, defining `add(left, right)`.
- `symbol-notes.md`, providing a document that forces semantic extraction.

It is not a production repository and should not contain user source files.

## Verification

```bash
python3 -m py_compile scripts/check-graphify-backends.py
python3 scripts/check-graphify-backends.py --dry-run
```
