# AGENTS.md

## Purpose

- Own the Python WhatsApp community source chat, supporting media, and derived community-operation documents.

## Ownership

- `chat.txt` and `chat.md` are source conversation records.
- `python-community-admin-meeting-playbook.md` is the consolidated meeting and 30-day pilot operating guide.
- Numbered image files are supporting source artifacts and must not be changed without an explicit request.

## Local Contracts

- Preserve source chat wording and timestamps when editing source records.
- Keep derived analysis and operational guidance separate from source conversation records.
- Do not expose phone numbers or unnecessary personal information in derived documents.
- Treat pilot assignments as unconfirmed until the named person explicitly accepts them.

## Work Guidance

- Use the playbook as the durable framework and a separate live record for meeting-specific decisions.
- Validate community processes manually before recommending implementation automation.
- Record owners, dates, evidence, reasons, unresolved issues, and review decisions explicitly.

## Verification

- Run Markdown lint on changed Markdown documents when the repository tooling is available.
- Reconcile meeting-specific records against explicit participant confirmations.

## Child DOX Index

- No child `AGENTS.md` files are currently required.
